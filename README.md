# README: Stuck Taskbar Notification Badge Fix

## 📖 Overview
The **Stuck Taskbar Notification Badge Fix** is a troubleshooting guide for a common Windows 10 and 11 annoyance: an app's taskbar icon (Discord, Teams, Slack, and others) shows a red unread badge when there is nothing unread, and new messages count up from that ghost number.

The guide starts with a quick two-step test that tells you whether the app or the Windows taskbar is causing the badge, so you can skip straight to the fixes that apply.

## 🗂 Contents of the Guide
The main document (`Guide.md`) is divided into these sections:
1. **How the Badge Actually Works** - A short explanation of who draws the badge (the app, not Windows) and why that matters.
2. **Step 1: Find Out Which One You Have** - Quick checks that point you to the app side, an out-of-sync counter, or the taskbar side.
3. **Phase 1: Find the Hidden Unread Item (App-Side)** - A Discord checklist (friend requests, message requests, muted servers, threads, Inbox, reload, cache clear, badge toggle), plus general steps for other chat apps.
4. **Phase 1B: When the App Shows Nothing Unread (Out-of-Sync Counter)** - For ghost counts that come from your account itself: checking in a browser and on a phone, spam requests, hidden channels, and workarounds.
5. **Phase 2: Clear a Stale Badge (Taskbar-Side)** - Restarting Windows Explorer, toggling taskbar badges, re-pinning, and a proper restart.
6. **Fixes That Don't Help** - Common tips found online that don't touch this problem.
7. **Quick Checklist** - A short summary to work through.

## ⚠️ Important Disclaimer
None of these steps modify the registry or system files. Clearing an app's cache folders is safe, but only delete the folders the guide names. Deleting an app's entire data folder can sign you out or reset its settings.

## 🚀 How to Use
Open `Guide.md` in any Markdown viewer, text editor, or code editor (such as VS Code, Notepad++, or Obsidian). Run **Step 1** first, then follow the phase it points you to, in order.
